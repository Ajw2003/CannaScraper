# Documentation

CannaScraper is a tool that checks stock and prices across every Canna Cabana store, because
the store's own website only shows you one location at a time. It can run from the command line,
as a local/public website, or as a Windows app you double-click.

This `docs/` folder is organized in tiers, each answering a different question:

- **`1-landing/`** — what this project is, and a map of everything else. Start here.
- **`2-roadmap/`** — what "done" looks like, milestone by milestone.
- **`3-state/`** — where the project actually stands right now.
- **`4-systems/`** — how each major piece works, in depth.
- **`5-today/`** — what's being worked on today, and why.
- **`6-decisions/`** — a log of decisions made and why, kept even after they're overtaken.
- **`plans/`**, **`archive/`**, **`generated/`** — work-in-progress plans, retired documents,
  and machine-generated output, respectively.

For the full technical walkthrough of how the scraper itself works, see the root
[`README.md`](../README.md) — this documentation set is a map and history on top of it, not a
replacement for it.

Start at [`docs/1-landing/README.md`](1-landing/README.md).
